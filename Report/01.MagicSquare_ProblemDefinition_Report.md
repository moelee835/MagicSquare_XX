## 1. 개요

4×4 마방진은 **행 4 + 열 4 + 대각선 2 = 10개 선**의 합이 모두 같아야 한다. 실습 조건은 숫자 **1~16**, 목표 합 **34**, **빈 칸(`0`) 2개**를 채워 완성하는 것이다.

본 보고서는 **솔루션 착수 전** 문제를 정의한다. Mom Test로 수집한 **과거 사실**만 진짜 문제로 쓰고, 프로그램·솔버·UI 같은 **표면 문제**는 범위 밖으로 둔다.

---

## 2. 페르소나

**4×4 부분 마방진을 손으로/코드로 다루는 학습자**

- OO·구조 설계 과제 맥락에서 마방진을 풂
- 빈 칸 2개를 채운 뒤 행·열·대각선 합을 직접 검산
- 손 계산·엑셀·초기 코드 등으로 같은 세션에서 채우기와 검증을 수행

## 3. Mom Test 결과

| 2 | *(미응답 — 알아챈 순간·매체)* |

### 3.2 Mom Test 증거 (인용)

1. “지난주 OO 과제에서”
2. “빈칸 2개 넣고 행·열·대각선 합 맞췄는데”
3. “대각선 하나를 빼먹어서 20분 날렸다.”

### 3.3 표면 문제 (금지 — PRD·구현 목표로 사용하지 않음)

- 4×4 마방진 **검증·채우기 프로그램**을 만든다.
- 행·열·대각선을 **자동으로** 맞춰 주는 **솔버 앱**이 필요하다.
- ECB **Validator/Solver 클래스**만 만들면 과제·학습이 해결된다.

### 3.4 진짜 문제 (한 문장)

OO 과제에서 빈 칸 2개를 채운 뒤 행·열·대각선 합을 맞췄다고 생각했지만 **대각선 하나를 검산에서 빠뜨려**, 틀린 상태로 **20분**을 쓴 뒤에야 잘못을 알게 되는 일이 반복된다.

| 요소 | 내용 |
|------|------|
| 불편 | 대각선(10선 중 일부) 검산 누락 |
| 비용 | 20분 재작업 |
| 판정 | “맞췄다” → 나중에 틀림 발견 |
| 재현 | OO 과제·빈칸 2·합 맞추기 패턴 |

## 4. 문제 정의 → 제품 방향 (솔루션 최소화)

### 4.1 주제 한 문장

**4×4·빈칸 2개·합 34를 채운 뒤, 10개 선(행4·열4·대각2) 검산을 빠뜨리지 않고 “맞음/틀림”을 바로 판정할 수 있게 한다** — 자동 채우기·GUI 앱이 아니라 **검증 규칙과 테스트 루프**로 “나중 20분”을 줄인다.

### 4.2 R-G-I-O

| 항목 | 내용 |
|------|------|
| **Role** | 4×4 부분 마방진 학습자. 채우기보다 **“맞다고 착각하기 전” 판정** 담당. |
| **Goal** | 빈 칸 2개를 채운 격자에 대해 **10선** 합이 34인지 한 번에 확인하고, 대각선 누락 검산이 다시 “맞췄다”로 끝나지 않게 한다. |
| **Input** | 4×4 정수 격자. `0` = 빈칸 2개. 나머지 1~16(중복 없음). 목표 합 **34**. 과제·슬라이드 **픽스처** 포함. |
| **Output** | **통과/실패**. 실패 시 **어느 선**(행·열·대각선, 인덱스)이 34가 아닌지. |

### 4.3 성공 기준 (Mom Test 증거 연결)

| ID | 기준 | 증거 |
|----|------|------|
| S1 | OO 과제와 동일 조건 픽스처로 검증 **재현** | “지난주 OO 과제에서” |
| S2 | **10선** 검증 포함; 대각선만 틀린 케이스에서 **실패** | “행·열·대각선 합 맞췄는데” (실제 누락) |
| S3 | 잘못된 격자 → **수 분 내** 실패 (20분 재작업 전) | “20분 날렸다” |

### 4.4 이번 단계에서 하지 않을 것

| 제외 | 이유 |
|------|------|
| 자동 채우기·솔버 완성 | 검증·판정이 선행 |
| GridUI·입력 앱 | 불편의 핵심은 UI가 아님 |
| ECB 전부 (`MissingFinder`, `Solver`, `ResultDisplay` 등) | 검증 Rule·Command·Test Loop 우선 |
| 빈칸 위치 탐색·힌트 | “채운 뒤 판정” 범위 |

## 5. 도메인 규칙 (MagicSquare)

| 규칙 | 설명 |
|------|------|
| 크기 | 4×4 |
| 값域 | 1~16, 중복 없음 (빈 칸 제외 시) |
| 빈 칸 | `0` 정확히 2칸 (시나리오별 채움 전·후 정의) |
| 10선 | 행 4, 열 4, 대각선 ↘ 1, 대각선 ↙ 1 |
| 목표 합 | 각 선의 합 = **34** |

**실패 인식 조건 (과거 사례·설계 참고, 3개 이상):**

1. 대각선(1개 이상) 합 ≠ 34  
2. 행 또는 열 합 ≠ 34  
3. 1~16 중복 또는 범위 밖 값  
4. 빈 칸 개수 ≠ 2 (시나리오 정의 위반)
