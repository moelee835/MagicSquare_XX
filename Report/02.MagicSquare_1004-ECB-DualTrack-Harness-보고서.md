## 1. 목적

PRD v0.1의 **Rule · Command · Test Loop** 구현에 앞서, ECB 3계층과 Dual-Track TDD를 위한 **최소 Harness(골격)** 를 마련한다.

- **코드·테스트 본문은 아직 없음** — 디렉터리·설정만
- 이후 Red → Green TDD는 `tests/control/` 등에 테스트 파일을 추가하며 진행

---

## 2. 산출물

### 2.1 디렉터리 구조

```
MagicSquare_XX/
├── pyproject.toml
├── src/
│   ├── entity/__init__.py
│   ├── control/__init__.py
│   └── boundary/__init__.py
└── tests/
    ├── entity/__init__.py
    ├── control/__init__.py
    └── boundary/__init__.py
```

### 2.2 ECB ↔ Dual-Track 매핑

| ECB 계층 | 소스 (`src/`) | 테스트 트랙 (`tests/`) | v0.1 우선순위 |
|----------|---------------|------------------------|---------------|
| Entity | `entity/` | `tests/entity/` | 이후 |
| Control | `control/` | `tests/control/` | **우선** (`SquareValidator`) |
| Boundary | `boundary/` | `tests/boundary/` | 이후 |

### 2.3 pyproject.toml

| 설정 | 값 | 의미 |
|------|-----|------|
| dev 의존성 | `pytest>=8.0` | Test Loop 단일 진입점 (PRD C1) |
| `testpaths` | `tests` | ECB별 테스트 디렉터리 수집 |
| `pythonpath` | `src` | `import entity`, `import control` 등 |

## 3. 확인 방법

### 3.1 pytest (메인)

```powershell
cd MagicSquare_XX
pip install -e ".[dev]"
pytest
```

**Harness만 있을 때 기대 결과:**

```
no tests collected in 0.01s
```

- exit code **5** = 테스트 0건 (골격 정상, 실패 아님)
- 테스트 파일 추가 후 → Red/Green 결과로 전환

### 3.2 ECB import (선택)

```powershell
$env:PYTHONPATH="src"
python -c "import entity, control, boundary; print('import ok')"
```

| PRD / 8계층 | Harness에서의 위치 |
